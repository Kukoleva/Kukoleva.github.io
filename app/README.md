# Beauty Studio — сайт кабинета косметолога

Динамическая версия сайта-визитки на React (Vite + TypeScript + Tailwind CSS 4).

Кабинет косметолога Куколевой Анастасии Геннадьевны в Гомеле:
г. Гомель, площадь Привокзальная, 1, гостиница «Гомель», 7 этаж, каб. 716.

## Запуск

```bash
bun install
bun run dev      # dev-сервер
bun run build    # сборка в dist/
bun run lint     # oxlint
```

## Структура

- `src/site.ts` — все данные: контакты, соцсети, прайс, фото
- `src/pages/Home.tsx` — главная (герой, услуги, работы, специалист, сертификаты, контакты)
- `src/pages/Prices.tsx` — страница цен (`#/prices`)
- `src/components/` — шапка, футер, карусель, лайтбокс с зумом, модальное окно связи
- `public/images/` — фотографии (работы, прайс-листы, сертификаты)
